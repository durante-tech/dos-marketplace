# Write Chapter -- Prose Generation

Write actual prose for a chapter using story bible milestones and rhetorical figures.

## When to Use

User says "write chapter [N]", "write the next chapter", "draft the opening". Requires a story bible (from BuildBible) or at minimum a clear understanding of the scene's purpose across all seven layers.

## Workflow

### Step 1: Load Chapter Context

Read the story bible for this chapter's milestones across all layers:
- **Meaning:** What thematic point does this chapter advance?
- **Character Change:** What happens to the sacred flaw here?
- **Plot:** What events occur (caused by previous chapter)?
- **Mystery:** What questions are planted or answered?
- **World:** What setting/atmosphere is needed?
- **Relationships:** Which bonds evolve?
- **Prose:** What rhetorical figures and voice are appropriate?

### Step 2: Scene Planning

Break the chapter into scenes. For each scene:
- **Purpose:** Why this scene exists (what it advances on which layers)
- **POV:** Whose perspective
- **Opening hook:** First line/paragraph that creates tension or curiosity
- **Beat sequence:** Key moments in order
- **Closing pull:** Last line that creates momentum into the next scene

### Step 3: Write Prose

Write the chapter following these principles:

**Character voice:** Every character speaks differently. Dialogue should be identifiable without attribution tags.

**Show the sacred flaw:** Don't describe the flaw -- show the character making decisions that reveal it.

**Cause-and-effect:** Every paragraph should feel like it causes the next. No "and then" transitions.

**Mystery management:** Plant questions early, delay answers strategically. Use end-of-scene hooks.

**Rhetorical figures (Mark Forsyth):** Deploy consciously at high-impact moments:
- Tricolon for important declarations
- Anadiplosis to build momentum
- Chiasmus for memorable reversals
- Hyperbaton for emphasis at critical beats

**Anti-cliche system:** Flag and replace:
- Phrases that "sound like writing" (e.g., "a single tear rolled down")
- Descriptions that could appear in any novel
- Emotions stated rather than shown
- Adverb-heavy dialogue tags
