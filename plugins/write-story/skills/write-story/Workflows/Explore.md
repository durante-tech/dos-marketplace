# Explore -- Creative Brainstorming

Divergent creative exploration: what-if scenarios, alternative paths, theme variations.

## When to Use

- User wants to brainstorm before committing to a direction
- Story bible exists but the user wants to explore alternatives
- User says "what if", "brainstorm", "explore", "try a different approach"

## Workflow

### Step 1: Identify Exploration Target

What layer(s) does the user want to explore?
- Character alternatives (different sacred flaw, different protagonist)
- Plot alternatives (different inciting incident, different climax)
- Theme variations (different controlling idea)
- World alternatives (different setting, different rules)
- Relationship configurations (different bonds, different dynamics)

### Step 2: Generate What-If Scenarios

For each exploration target, generate 3-5 divergent options. Each option should:
- Be genuinely different (not a minor variation)
- Be internally consistent across all seven layers
- Include a brief assessment of strengths and risks

```markdown
### What If: [Exploration Target]

**Option A: [Title]**
- [Description]
- Strengths: [what this unlocks narratively]
- Risks: [what this makes harder]

**Option B: [Title]**
- [Description]
- Strengths: ...
- Risks: ...

**Option C: [Title]**
- [Description]
- Strengths: ...
- Risks: ...
```

### Step 3: Cascade Analysis

For the most promising options, trace the implications across all seven layers:
- If we change [X], how does it affect meaning?
- Does this change the sacred flaw or transformation?
- What plot events would need to change?
- How does this alter the mystery structure?
- Does the world still pressure the flaw effectively?
- Which relationships are affected?
- Does the prose voice need to shift?

### Step 4: Deliver Exploration Report

Present options with clear recommendation. Let the user choose.

## Validation

- [ ] Multiple genuinely different options generated
- [ ] Cross-layer implications traced
- [ ] Clear recommendation provided
- [ ] User decision captured for bible update
