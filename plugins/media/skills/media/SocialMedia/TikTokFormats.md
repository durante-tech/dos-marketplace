# TikTok Image Formats (2025-2026)

Complete reference for all TikTok image types, dimensions, and specifications.

## Safe Zone Reference (1080x1920 canvas)

| Zone | Pixels from Edge | What Occupies It |
|------|-----------------|------------------|
| Top | ~140px | Device status bar, notch/Dynamic Island |
| Bottom (organic) | ~324px | Caption, sound attribution, engagement bar |
| Bottom (ads) | ~370px | CTA button + "Sponsored" label |
| Right | ~164px | Like, comment, share, bookmark, profile |
| Right (Jan 2026+) | ~184px | Added "Add to Playlist" button (+20px) |
| **Effective safe area** | **~960x1386px** | **Centered within 1080x1920** |

## Strategic Notes

- **9:16 (1080x1920)** dominates everything on TikTok — it's the only format that fills the screen
- Safe zones are critical — bottom 324-370px and right 164-184px are always overlaid with UI
- Photo carousels at 1:1 or 4:5 get letterboxed — only 9:16 is truly full-screen
- For shop products, strict 1:1 with white backgrounds and no text overlays
