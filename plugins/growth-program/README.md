# GrowthProgram

> Run a product's social-media presence + growth campaign program end-to-end — strategy, multi-channel calendar, a recurring creative/materials engine, publish/engage/measure social ops, a GEO/AEO pillar, measurement, and coordination — from project knowledge + a campaign subject.

---

## The Problem

Running a product's growth ad-hoc per session forfeits the structured program that makes presence
compound: the campaign calendar, the creative materials, the publishing cadence, the GEO/answer-engine
play, and the measurement loop get re-invented every time — and unsourced stats and off-brand assets
slip through.

---

## The Solution

The **GrowthProgram** pack packages an 8-workflow, 7-phase program behind a single `SKILL.md` entry card
with the canonical RFC-0011 distribution manifest. Social presence + the campaign calendar + the
materials engine are first-class; GEO/AEO is one pillar. A 5-seat council vets the program and an
adversarial integrity guard (no fabricated stats, no fake reviews, brand + platform-ToS compliance) gates
every artifact. It composes existing DOS skills — Brand, Dispatch, Media, SocialMedia, StreamRig,
Research, Sentinel, MemPalace — rather than re-implementing them.

Generalizes `durante-tech/altyaa-turbo#251` (the GEO pillar) into the full presence + campaign program.
