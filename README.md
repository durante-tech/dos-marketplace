DuranteOS (DOS) — the Durante Operating System as Claude Code plugins. dos-core is the base substrate every pack-plugin requires; the remaining plugins are the public DOS capability packs.

## Install

```
/plugin marketplace add <owner>/<this-repo>
/plugin install dos-core@durante-dos
```

Install `dos-core` first — every other DOS plugin declares it as a dependency
(the `requires` field in each plugin's `.claude-plugin/dos.json` sidecar) and expects
its substrate (Algorithm doctrine, core hooks, MemPalace MCP) to already be present.
Install additional plugins the same way:

```
/plugin install <plugin-name>@durante-dos
```
